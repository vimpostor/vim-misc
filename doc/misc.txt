INTRODUCTION						*misc-introduction*

This plugin provides a couple of miscellaneous vim features, including:
- C-style header/source pair generation
- Improved file completion
- Thesaurus integration with `aiksaurus`
- Automatic indent detection

------------------------------------------------------------------------------
CONFIGURATION						*misc-configure*

	g:misc_options					*g:misc_options*
All user-facing options are configured with the |g:misc_options| variable,
which is a |Dictionary| containing all options as key-value pairs. The default
options can be retrieved with |misc#default_options()|.
The following keys are available:

	"default_mappings"				*misc_options_default_mappings*
		If truthy, use the default keybindings. When you disable this,
		refer to |misc-api| for how to setup your own
		keybindings.

------------------------------------------------------------------------------
API							*misc-api*

	misc#boilerplate#header_create()		*misc#boilerplate#header_create()*
		Generates a new C-style header/source pair with the given
		name.

	misc#file#compl()				*misc#file#compl()*
		Completes the file under the cursor, with improved UX compared
		to |i_CTRL-X_CTRL-F|. Trailing slashes are not autocompleted
		and after insertion of `/`, files in the next directory are
		automatically completed again.

	misc#thesaurus#thesaur()			*misc#thesaurus#thesaur()*
		Consults a |thesaurusfunc| compatible integration of the
		external `aiksaurus` tool for synonyms, see |i_CTRL-X_CTRL-T|.

	misc#indent#autoindent()			*misc#indent#autoindent()*
		A poor man's editorconfig, that consults the surrounding
		content of the current file to deduce the best matching
		indentation settings.

------------------------------------------------------------------------------
COMMANDS						*misc-commands*

	Cunit						*:Cunit*
		Calls |misc#boilerplate#header_create()| with the given
		arguments.
