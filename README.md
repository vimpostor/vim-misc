# vim-misc

This plugin provides a couple of miscellaneous vim features.
For more information consult the extensive help page under `:help misc`.

[![asciicast](https://asciinema.org/a/1129251.svg)](https://asciinema.org/a/1129251)

# Installation

Using **vim-plug**:

```vim
Plug 'vimpostor/vim-misc'
```
